# Тексты для @BotFather

Узбекский — основной: бот разговаривает с фермером. Русский вариант
приложен для наблюдателей-агрономов и для заявки, не для самого бота.

---

## 1. Имя · `/setname`
Лимит 64 символа.

```
SUV AI — aqlli sug'orish
```

---

## 2. Короткое описание · `/setabouttext`
Лимит 120 символов. Видно в профиле бота и в поиске.

```
Dalangiz uchun sug'orish tavsiyasi: qachon va qancha suv kerak. Sun'iy yo'ldosh, ob-havo va FAO-56 hisobi.
```

Русский вариант (105 симв.):

```
Рекомендации по поливу вашего поля: когда и сколько воды. Спутник, погода и расчёт FAO-56.
```

---

## 3. Описание · `/setdescription`
Лимит 512 символов. Экран до нажатия «Запустить».

```
Men sizga dalangizni qachon va qancha sug'orish kerakligini aytaman.

Har bir dala uchun alohida hisoblayman:
🛰 Sentinel-2 sun'iy yo'ldoshi — dalangiz qanday o'sayotganini ko'radi
🌤 16 kunlik ob-havo prognozi
💧 FAO-56 bo'yicha tuproq namligi balansi
⚡ Nasos soatlari va so'mdagi xarajat

Javob bitta jumla bo'ladi: "Payshanba kuni nasosni 9 soat ishlating".

Boshlash uchun «Запустить» tugmasini bosing.
```

Русский вариант:

```
Подскажу, когда и сколько поливать именно ваше поле.

Считаю для каждого поля отдельно:
🛰 снимок Sentinel-2 — как поле растёт на самом деле
🌤 прогноз погоды на 16 дней
💧 водный баланс почвы по методике FAO-56
⚡ часы работы насоса и расход в сумах

Ответ — одна фраза: «В четверг включите насос на 9 часов».

Нажмите «Запустить», чтобы начать.
```

---

## 4. Команды · `/setcommands`
Вставить блок целиком одним сообщением.

```
start - Ro'yxatdan o'tish / dalani qo'shish
suv - Bugungi sug'orish tavsiyasi
bajardim - Sug'organimni belgilash
tejaldi - Mavsumda tejalgan suv
yordam - Yordam va tugmalar haqida
```

---

## 5. Аватар · `/setuserpic`
Файл `brand/avatar.png` (512×512).

---

## Порядок настройки

Открыть [@BotFather](https://t.me/BotFather) → `/mybots` → выбрать
`@suv_ai_bot` → **Edit Bot**, затем по очереди: Edit Name, Edit
Description, Edit About, Edit Botpic, Edit Commands.
