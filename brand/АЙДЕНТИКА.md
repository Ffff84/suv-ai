# SUV AI — айдентика

Знак: капля воды, внутри которой — борозды поля, над ней — искра
спутникового сигнала. Три сущности продукта в одной форме: вода, земля,
данные. Работает в один цвет, читается в кружке Telegram 40 px.

## Файлы

| Файл | Назначение |
|---|---|
| `logo.svg` | Горизонтальный локап: знак + SUV AI + тэглайн. Шапки документов, сайт, титульный слайд |
| `logo-mark.svg` | Только знак. Фавиконка, соцсети, водяной знак на слайдах |
| `logo-mono.svg` | Одноцветный (наследует `currentColor`). Печать, гравировка, тёмные фоны |
| `avatar.png` | 512×512 — аватар Telegram-бота (@suv_ai_bot) |

Для диаграмм: факт/«как было» — оранжевый `#eb6834`, расчёт AI — Suv
Blue. Пара проверена на контраст и дальтонизм, не менять местами.

## Шрифт

**Inter** (free, rsms.me/inter) — заголовки ExtraBold 800, текст
Regular/Medium. Нет под рукой — системный: Segoe UI / SF Pro / Arial.
Кириллица и узбекская латиница поддерживаются.

## Тэглайн

- UZ: **Har bir dala uchun aqlli sug'orish**
- RU: **Умный полив для каждого поля**

## Правила

- Знак не растягивать, не поворачивать, не перекрашивать волны.
- Охранное поле вокруг знака — половина его ширины.
- На фото и тёмном фоне — только `logo-mono.svg` белым.
- Искра всегда зелёная либо в цвет знака; отдельно от капли не живёт.
